# 控えめカード型の目次

## Summary

記事本文の先頭にある既存の折りたたみ目次を、細い枠線・小さな見出し・左アクセントで整えた控えめなカードへ変更する。表示条件と開閉状態は維持する。

## Changes

- `details` / `summary` と Hugo 生成の目次を維持し、見出し用のクラスだけを加える。
- カスタム CSS で、枠線、左アクセント、階層ごとの余白、ホバーとキーボードフォーカスを定義する。
- テーマのライト／ダーク色を使い、JavaScriptや依存関係は追加しない。

## Verification

- Hugo build を実行する。
- 長い技術記事で開閉と階層表示を確認する。
- ライト・明示ダーク・OS設定ダークで背景が透明かつ入れ子ガイド線がカードの左アクセントより薄いことを確認する。
- 目次リストと入れ子リストに上部余白が残らないことを確認する。
- モバイル幅で横はみ出しがなく、目次ボタンが見出し名だけを読み上げることを確認する。
